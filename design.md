# Portfolio Design Style Guide

## Design Philosophy

### Color Palette
- **Primary**: Deep slate blue (#1e293b) - Professional, trustworthy, tech-focused
- **Secondary**: Warm amber (#f59e0b) - Innovation, creativity, energy
- **Accent**: Soft teal (#14b8a6) - Growth, balance, modern tech
- **Neutral**: Cool gray (#64748b) - Sophistication, readability
- **Background**: Off-white (#fafafa) - Clean, minimal, professional

### Typography
- **Display Font**: "Canela" - Bold serif for headings and hero text
- **Body Font**: "Suisse Int'l" - Clean sans-serif for readability
- **Code Font**: "JetBrains Mono" - Technical content and code snippets
- **Hierarchy**: Large display headings, medium section titles, small body text

### Visual Language
- **Minimalist Aesthetic**: Clean layouts with generous white space
- **Geometric Patterns**: Subtle grid systems and structured layouts
- **Tech-Inspired**: Circuit board patterns, data visualization elements
- **Professional**: Corporate-friendly with creative edge

## Visual Effects & Styling

### Used Libraries
- **Anime.js**: Smooth micro-interactions and element transitions
- **ECharts**: Interactive data visualizations and performance charts
- **p5.js**: Creative coding background effects and particle systems
- **Splide.js**: Smooth project showcase carousels
- **Shader-park**: Subtle background shader effects

### Animation Effects
- **Typewriter Animation**: Hero text reveals with staggered timing
- **Stagger Reveals**: Content sections animate in sequence
- **Hover Transformations**: 3D tilt effects on project cards
- **Scroll Parallax**: Subtle depth effects on background elements
- **Particle Systems**: Floating geometric shapes in hero section

### Header Effect
- **Animated Background**: Subtle particle system with geometric shapes
- **Gradient Overlay**: Soft color transitions from primary to secondary
- **Typewriter Text**: Name and title with cursor animation
- **Floating Elements**: Abstract ML/AI inspired shapes

### Interactive Elements
- **Button Hover**: 3D lift with shadow expansion
- **Card Interactions**: Smooth scale and glow effects
- **Form Focus**: Animated border highlights and field validation
- **Navigation**: Smooth underline animations

### Data Visualization Style
- **Consistent Color Scheme**: Using primary palette for all charts
- **Smooth Animations**: Data points animate in with easing
- **Interactive Tooltips**: Hover states with detailed information
- **Responsive Design**: Charts adapt to screen size

### Background Treatment
- **Consistent Base**: Off-white background throughout
- **Subtle Patterns**: Light geometric grid overlay
- **Section Dividers**: Clean lines and spacing between content areas
- **No Gradients**: Solid colors only, maintaining professional appearance

### Mobile Considerations
- **Touch-Friendly**: Larger interactive areas for mobile
- **Simplified Animations**: Reduced motion for performance
- **Readable Typography**: Adjusted font sizes for small screens
- **Optimized Images**: Compressed assets for faster loading
